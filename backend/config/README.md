# 客户端策略配置（方案 C）

`client-policy.config.json` 是客户端申报规则的唯一维护入口，生产环境不再通过管理端页面维护区域、项目、材料要求或申报方案。

- `regions`：维护总负责人可以分发的区域。每个区域需要唯一 `code`、`name`、`level`，子区域使用 `parentCode`。
- `projects`：维护客户端可用申报项目。
- `materials`：维护材料清单和材料项。
- `scheme`：维护申报方案、资格/材料/评分/流程规则及能力开关。

后端启动时会校验并同步该文件到业务表；客户端只读取同步后的业务数据。修改配置后重启后端即可生效。配置为空数组表示当前没有可分发区域或可用申报项目，不会自动生成示例数据。
