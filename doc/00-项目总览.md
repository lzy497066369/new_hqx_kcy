# 项目总览

## 项目定位

这是一个面向企业业务管理的前后端一体项目。当前仓库已经明确了三个核心部分：

- `vue-admin/apps/web-admin`：后台管理系统，业务上简称 `vue-admin`
- `vue-admin/apps/web-client`：客户端操作系统，业务上简称 `vue-client`
- `backend`：NestJS + TypeORM + MySQL 5.6 兼容的正式后端

项目当前的重点不是“再复制一套旧文档”，而是按仓库里的真实代码，把接口、页面和数据库逐步收敛成一套可维护的正式方案。

## 当前状态

- 后台管理系统已经有系统页骨架，包含：
  - `/system/user`
  - `/system/role`
  - `/system/menu`
  - `/system/dept`
- 后台管理系统已具备系统管理、企业管理、政策管理、政策采集同步与 AI 审计等页面和接口；系统管理四页已接入正式接口。
- 客户端操作系统已具备企业切换、资料维护、材料上传、政策库、项目申报、财税与研发知识产权等业务页面及 API。
- 后端已实现认证、用户与权限、企业资料、客户端业务、政策项目与采集、AI、上传和工作台模块。
- 后端已在系统管理、企业管理、政策管理和政策采集入口执行服务端权限码校验；AI 管理、天眼查企业导入和项目老师绑定仅允许系统管理员访问。
- 数据库交付已区分新环境初始化与已有库升级：`schema.mysql56.sql` 用于新库，已有库通过受控迁移清单和 `sys_schema_migration` 记录执行状态。
- 当前首要工作是收敛安全与权限边界、数据库迁移基线和关键流程自动化验证，避免继续横向扩展造成维护成本上升。
- 数据库目标版本是线上兼容的 `MySQL 5.6.50-log`。

## 主要技术栈

- 前端：Vue 3、TypeScript、Vite、Vben Admin
- 后端：NestJS、TypeORM、mysql2
- 文档：Markdown、Swagger

## 现在建议优先做的事

1. 收敛认证安全、服务端权限和企业数据隔离。
2. 停止依赖运行时自动同步，确定唯一的 SQL 初始化与增量迁移基线。
3. 为登录、企业切换、资料提交、项目申报、政策采集补齐最小自动化回归。
4. 再根据验收链路处理具体业务缺口，避免继续无序横向扩展。

## 结论

这个项目现在最重要的是先稳住“登录、用户、菜单、系统管理”的后台核心闭环，再逐步补齐客户端业务流程。只要这两条链路稳定，后续其他业务模块就可以按同样方式持续迭代。
