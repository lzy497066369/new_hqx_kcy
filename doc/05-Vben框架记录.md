# Vben 框架记录

## 官方地址

- 文档站：<https://doc.vben.pro/>
- 演示站：<https://www.vben.pro/#/system/menu>

## 简要说明

Vben Admin 是一个面向企业中后台的管理系统框架。

我当前记录时，文档站首页显示的版本号为 `5.7.0`，并提供了文档、组件、演示和历史版本入口。

## 适用场景

- 企业后台管理系统
- 中后台业务配置与权限管理
- 需要快速搭建 Vue 3 技术栈管理端项目的场景
