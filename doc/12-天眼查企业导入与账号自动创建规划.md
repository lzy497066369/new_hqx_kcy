# 12-天眼查企业导入与账号自动创建规划

## 1. 文档目标

本文档用于规划后台管理系统“新增企业”流程升级：管理员输入公司名称后，系统调用天眼查 API 检索企业，拉取企业基本信息和主要人员，自动完成企业资料导入、天眼查调用留痕、企业人员落库，以及企业负责人/企业用户账号自动创建。

本期只做后台管理系统 P0 最小闭环，不包含客户端企业绑定流程，也不做第二阶段增强能力。

## 2. 当前仓库落点

### 2.1 后端

- 技术栈：NestJS + TypeORM + MySQL 5.6 兼容 SQL
- 企业模块入口：`backend/src/modules/enterprise`
- 当前企业资料接口：`/enterprise/profile/*`
- 当前企业账号能力：
  - `EnterpriseAccountService` 负责创建 `sys_user`
  - `biz_enterprise_owner` 绑定企业负责人
  - `biz_enterprise_user` 绑定企业用户

### 2.2 前端

- 技术栈：Vue 3 + Vite + TypeScript + Vben Admin
- 页面入口：`vue-admin/apps/web-admin/src/views/enterprise/profile/list.vue`
- 当前“新增企业”为手工表单弹窗，需要改造成导入向导

### 2.3 已识别的 P0 约束

1. 当前企业主表 `biz_enterprise` 仍保留较多手工录入字段，本期先收敛写入范围，不做历史字段删除。
2. 当前 `EnterpriseAccountService` 会校验 `phone/email` 唯一；与“手机号允许重复”的业务规则冲突，本期必须调整为仅 `username` 唯一。
3. 当前用户表 `sys_user` 没有 `must_change_password` 字段，因此本期不新增该字段，只在备注中体现初始密码信息。
4. 当前地区表 `biz_region` 只有名称层级信息，没有标准行政区编码；本期先同步省/市/区名称，不做区域表自动映射增强。

## 3. P0 目标效果

后台新增企业流程调整为：

1. 输入公司名称
2. 调用天眼查企业搜索接口
3. 记录搜索调用日志
4. 展示候选企业
5. 选择目标企业
6. 调用企业基本信息及主要人员接口
7. 记录详情调用日志
8. 进行企业去重判断
9. 创建或复用企业主表
10. 写入企业基本信息表
11. 写入企业主要人员表
12. 自动创建企业负责人和企业用户账号
13. 返回企业详情页

## 7. 业务规则

### 7.1 企业去重

优先顺序：

1. `credit_code`
2. `tyc_enterprise_id`
3. `name` 仅作为提示

重复导入时：

- 不重复创建企业
- 不重复创建账号
- 返回“企业已存在”，并提供现有企业 ID

### 7.2 人员去重

- 同一企业内按 `enterprise_id + name + position` 去重
- 不同企业之间不做人员去重

### 7.3 账号创建

- 法人创建 `enterprise_owner`
- 其他主要人员创建 `enterprise_user`
- 默认密码 `123456`
- 用户名规则：
  - 法人：`owner_${enterpriseId}`
  - 普通用户：`user_${enterpriseId}_${序号}`
  - 冲突时追加短随机码

### 7.4 手机号规则

- 手机号允许为空
- 手机号允许重复
- 手机号仅作联系方式，不作唯一键判断

## 8. 页面规划

后台“企业资料 > 新增企业”改为三步导入：

1. 企业检索
2. 导入预览
3. 确认导入

P0 页面信息范围：

- 候选列表：企业名称、统一社会信用代码、法定代表人、成立日期、经营状态、注册地址
- 预览信息：企业名称、统一社会信用代码、经营状态、法定代表人、注册资本、成立日期、企业类型、登记机关、注册地址、经营范围、省市区、联系电话、邮箱、官网
- 人员预览：姓名、职位、人员类型、是否法人、是否创建账号

## 9. 验收标准

1. 后台新增企业只需要输入公司名称
2. 能调用天眼查搜索接口并展示候选企业
3. 每次天眼查 API 调用都写入 `biz_tianyancha_api_call_log`
4. 搜索和详情完整返回都保存到 `response_json`
5. 可拉取企业基本信息和主要人员
6. `biz_enterprise` 成功创建并同步高频字段
7. `biz_enterprise_basic_info` 保存工商字段
8. `biz_enterprise_person` 保存法人和主要人员
9. 自动创建企业负责人账号
10. 自动创建企业用户账号
11. 默认密码为 `123456`
12. 同手机号允许在不同企业创建多个账号
13. 重复导入不会重复创建企业和账号
14. 前端导入流程可完整走通
