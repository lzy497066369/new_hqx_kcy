# 申报详情诊断评分与草稿开发顺序

## 1. 阶段目标

本阶段把企业资料真正接入申报详情，但继续保持职责边界：

```text
企业资料：维护企业主数据
企业申报：只读引用、诊断、评分、测算、生成草稿、导出准备
```

申报详情中不直接修改企业基础信息、财税、人员、IP/RD/PS/成果转化等主数据。需要补齐资料时，统一跳转到企业资料对应模块。

## 2. 功能结构

| 区块 | 作用 | 数据来源 |
| --- | --- | --- |
| 诊断与准备度 | 展示材料准备度、风险等级、缺失资料和补齐入口 | 企业资料、材料准备度规则 |
| 高企评分测算 | 按高企评分规则输出分项得分、扣分原因和建议 | 财税、人员、IP、RD、PS、成果转化 |
| 申报书草稿 | 自动生成申报书初稿，企业主数据字段只读 | 企业资料、申报补充说明 |
| 完善与导出准备 | 导出前检查字段、附件、证据链完整度 | 申报草稿、附件、材料准备度 |

## 3. 开发顺序

### P0：申报详情增加诊断与准备度

目标：在“我的申报详情”中展示准备度诊断，并能从缺失项跳转到企业资料补齐。

任务：

| 顺序 | 任务 |
| --- | --- |
| 1 | 梳理申报详情页面和材料准备度接口 |
| 2 | 将申报详情中的材料准备度区块升级为“诊断与准备度” |
| 3 | 复用现有申报材料准备度接口 |
| 4 | 展示准备度分数、风险等级、缺失字段、缺附件和关联证据链 |
| 5 | 缺失项提供“去企业资料补齐”按钮 |
| 6 | 跳转到企业资料对应模块，并保持申报页只读 |

验收：

| 验收项 | 标准 |
| --- | --- |
| 看得清 | 申报详情可看到准备度分数、风险等级、缺失项 |
| 去得准 | 缺失项可跳转财税、人员、研发与知识产权、合同发票等企业资料模块 |
| 边界正确 | 申报详情不直接编辑企业资料 |

### P1：评分引擎重置

目标：按高企评分规则输出当前企业预估分和风险项。

建议评分结构：

| 评分项 | 建议分值 | 数据来源 |
| --- | --- | --- |
| 知识产权 | 30 | IP 数量、类型、权属、核心支持、关联 RD/PS |
| 科技成果转化 | 30 | 成果转化数量、年度、关联 IP/RD/PS/合同发票 |
| 研发组织管理 | 20 | RD 项目、制度文件、研发费用、人员参与 |
| 成长性指标 | 20 | 近三年收入、净资产、利润等财税数据 |

验收：

| 验收项 | 标准 |
| --- | --- |
| 可测算 | 根据企业资料自动算出当前高企预估分 |
| 可解释 | 每项得分有依据、扣分原因和补齐建议 |
| 可行动 | 低分项能跳转到对应企业资料模块 |

### P2：申报书草稿

目标：从企业资料生成申报书初稿。

任务：

| 顺序 | 任务 |
| --- | --- |
| 1 | 定义申报书草稿数据结构 |
| 2 | 建立企业基础信息、财税、人员、IP、RD、PS、成果字段映射 |
| 3 | 增加生成草稿接口 |
| 4 | 前端展示草稿预览 |
| 5 | 企业主数据字段只读，修改时跳企业资料 |
| 6 | 仅允许编辑申报说明类补充字段 |

验收：

| 验收项 | 标准 |
| --- | --- |
| 能生成 | 点击生成后出现申报书草稿 |
| 来源清楚 | 字段能区分来自企业资料还是申报补充 |
| 不越界 | 企业主数据不能在申报草稿里直接修改 |

### P3：申报书完善与导出准备

目标：导出前检查字段、附件和证据链。

任务：

| 顺序 | 任务 |
| --- | --- |
| 1 | 增加导出准备检查接口 |
| 2 | 检查基础字段完整性 |
| 3 | 检查附件完整性 |
| 4 | 检查 RD/IP/PS/成果/合同发票证据链完整性 |
| 5 | 展示“可导出 / 需补齐 / 高风险”状态 |
| 6 | 先形成导出准备清单，后续再接正式 Word/PDF/Excel 导出 |

验收：

| 验收项 | 标准 |
| --- | --- |
| 能检查 | 导出前能看到缺哪些字段和附件 |
| 能定位 | 每个问题能跳转到对应资料或草稿位置 |
| 可扩展 | 后续能接正式 Word/PDF/Excel 导出 |
