# 高企申报助手最终验收与交付说明

## 1. 交付范围

本版本完成高新技术企业申报辅助链路的第一版可交付闭环：

```text
企业资料维护 -> 高企资料完整度 -> 申报详情诊断 -> 高企评分测算 -> 申报书草稿 -> 导出准备检查 -> Excel 数据包导出
```

边界保持不变：

```text
企业资料：维护企业主数据
企业申报：只读引用、诊断、评分、草稿、导出准备、导出数据包
```

申报详情中不可直接修改企业基础信息、财税、人员、IP、RD、PS、成果转化、合同、发票等企业主数据；需要修改时统一跳转企业资料对应模块。

## 3. 演示数据准备清单

建议准备一家公司作为演示企业，数据尽量覆盖完整链路。

| 模块 | 演示数据要求 | 验收目标 |
| --- | --- | --- |
| 企业基本信息 | 企业名称、统一社会信用代码、法定代表人、成立时间、注册地址、所属行业、经营范围 | 申报书草稿能生成企业基本信息 |
| 财税资料 | 近三年财务数据，含销售收入、净资产、研发费用、高新收入 | 成长性评分和草稿财税区块可用 |
| 纳税审计 | 至少一条年度审计/纳税材料并有附件 | 导出准备不提示缺审计附件 |
| 人员资料 | 员工花名册，标记科技人员，科技人员占比建议达到 10% | 研发组织管理评分可解释 |
| 知识产权 IP | 至少 1 条核心 IP，补齐权利人、I/II 类、证书附件、关联 RD/PS | 知识产权评分和证据链可用 |
| 研发项目 RD | 至少 3-4 条 RD 项目，含项目编号、负责人、组织方式、创新点、研发费用 | 研发组织管理和草稿 RD 区块可用 |
| 高新产品/服务 PS | 至少 1-2 条 PS，含高新收入、关键技术、关联 RD/IP/成果 | 成果转化证据链可用 |
| 成果转化 | 至少 5 条成果转化，含年度、方式、证明材料、关联 RD/IP/PS/合同/发票 | 成果转化评分和导出准备可用 |
| 合同发票 | 至少 1 条合同和 1 条发票，关联 PS 或成果转化 | 证据链检查可用 |
| 制度文件 | 研发组织管理、成果转化、人才激励等制度文件 | 研发组织管理评分可用 |
| 企业证书/照片/账号 | 可选补充 | 企业资料完整度更高 |

## 4. 验收流程

### 4.1 企业资料侧

1. 进入企业资料首页。
2. 查看“高企申报资料完整度”卡片。
3. 点击缺口项，确认能跳转到对应企业资料模块。
4. 补齐财税、人员、IP、RD、PS、成果转化、合同、发票、制度文件。
5. 刷新统计，确认高企资料完整度提升。

验收标准：

| 检查项 | 标准 |
| --- | --- |
| 高企完整度可见 | 企业资料首页能看到高企申报资料完整度 |
| 缺口可定位 | 缺口项能跳转对应模块并携带 `tab` |
| 主数据边界正确 | 企业资料负责编辑，申报详情不编辑主数据 |

### 4.2 申报详情侧

1. 进入“我的申报详情”。
2. 查看“高企评分测算”。
3. 查看“诊断与准备度”。
4. 查看“申报书草稿”。
5. 查看“申报书完善和导出准备”。
6. 点击“导出数据包”。

验收标准：

| 检查项 | 标准 |
| --- | --- |
| 评分可解释 | 评分项展示规则、依据、证据链、扣分原因和补齐建议 |
| 诊断可行动 | 缺失资料能跳企业资料补齐 |
| 草稿只读边界 | 企业资料字段只读，申报补充说明可编辑 |
| 导出准备可判断 | 展示可导出、需补齐或高风险状态 |
| 数据包可下载 | 成功下载 `{项目名称}-申报数据包.xlsx` |

### 4.3 导出数据包

Excel 数据包应包含：

| Sheet | 验收内容 |
| --- | --- |
| 导出说明 | 项目、状态、风险、材料准备度、草稿完整度、评分 |
| 导出问题清单 | 阻断项、提醒项、来源、动作、模块、页签 |
| 申报书草稿 | 章节、记录、字段、内容、来源、是否可编辑 |
| 评分测算 | 评分项、得分、规则摘要、证据链、扣分原因、建议 |
| 材料准备度 | 材料项、状态、缺失字段、附件、证据链 |

## 5. 关键接口

| 接口 | 用途 |
| --- | --- |
| `GET /client/enterprise-profile/stats` | 企业资料完整度和高企资料完整度 |
| `GET /client/projects/:id/material-readiness` | 项目材料准备度 |
| `GET /client/declarations/:id/material-readiness` | 申报材料准备度 |
| `GET /client/projects/:id/gaoxin-score` | 项目高企评分测算 |
| `GET /client/declarations/:id/gaoxin-score` | 申报高企评分测算 |
| `GET /client/declarations/:id/gaoxin-book` | 申报书草稿 |
| `PUT /client/declarations/:id/gaoxin-book` | 保存申报补充说明 |
| `GET /client/declarations/:id/gaoxin-export-readiness` | 导出准备检查 |
| `GET /client/declarations/:id/gaoxin-export-package` | 导出 Excel 数据包 |
