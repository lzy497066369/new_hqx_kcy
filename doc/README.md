## 说明

- `00-项目总览.md`：先看这个，快速了解项目现状和边界。
- `04-正式前后端对接文档.md`：前后端联调的核心依据。
- `06-系统管理前端对接说明.md`：系统管理模块的开发说明和字段建议。
- `07-后台管理系统正式化计划.md`：当前阶段的开发清单、优先级和验收标准。
- `08-功能总表.md`：按功能项汇总当前已明确、待完成和后续扩展内容。
- `10-客户端信息采集一期规划.md`：客户端企业资料采集、材料模板下载上传、审核闭环的一期规划。
- `11-客户端开发顺序.md`：把客户端一期内容拆成 P0/P1/P2/P3 开发顺序、交付物和验收点。
- `14-申报材料要求与准备度开发方案.md`：申报项目材料要求、企业资料匹配、准备度评分和开发顺序。
- `15-高企申报助手融合规划.md`：把 `declare-assistant` 中的高企评分、诊断、申报书能力融合到当前申报项目体系的规划。
- `16-企业资料整体方案与开发顺序.md`：企业资料主数据、财税导入、人员导入、研发与知识产权、PS/成果转化和开发顺序规划。
- `19-AI能力嵌入现有页面开发规划.md`：规划 AI 大模型能力如何嵌入现有政策、企业、申报、审核页面，而不是单独建设大量 AI 页面。
- `22-研发与知识产权AI批量生成规范与开发顺序.md`：规划知识产权 PDF 批量识别、成果转化批量生成、RD 立项报告生成、PS 高新产品批量生成和证据链验收顺序。
- `23-统一企业服务中心重构规划.md`：将客户端能力按后台企业工作流重组，定义企业上下文、权限边界、页面信息架构和实施阶段。

## 当前状态

现有文档已从“复制来的后端说明”整理为“以当前仓库实际情况为准”的版本，且当前阶段已经进入 P1 的收尾同步。

当前目录对应关系建议统一按下面理解：

- `vue-admin/apps/web-admin`：后台管理系统，业务上简称 `vue-admin`
- `vue-admin/apps/web-client`：客户端操作系统，业务上简称 `vue-client`
- `backend`：正式后端

后续如果接口或页面范围变化，优先更新 `00`、`04` 和 `06` 三份文档。
