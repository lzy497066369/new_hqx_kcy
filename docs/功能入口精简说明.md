# 功能入口精简说明

> 本轮只做页面入口和信息层级收敛，不删除业务接口、数据库字段、业务页面或既有路由。

## 一、调整目标

围绕“企业建档 → 资料补齐 → 政策匹配 → 创建申报 → 材料准备 → 审核补正 → 申报结果”的服务主链路，减少首页和工作台中与当前任务无关的并列入口，让用户优先完成当前阶段的下一步操作。

## 二、客户端首页

### 保留并突出

- 当前企业、企业切换、刷新
- 服务进度（首页唯一的业务主入口）
- 侧边栏中的三个核心业务入口：企业资料、政策匹配、我的申报

### 已移除的首页及全局入口

- 首页“常用功能”快捷区：删除重复入口，所有业务操作统一从服务进度各阶段进入。
- 通知中心：从客户端全局顶栏移除，提醒回收到服务进度、申报详情或审核补正场景。
- 同步中心：从客户端全局顶栏移除，不再作为用户需要主动关注的业务入口。
- 待办事项、申报待办：从菜单移除，合并到服务进度和申报详情的下一步操作。
- 个人情况、账号资料：从企业业务导航移除，不再干扰企业办理流程。
- 公司切换：从菜单移除，仅保留当前企业卡片内的切换公司按钮。
- 材料模板中心：并入企业资料，作为资料补齐过程中的内部页面。
- 项目列表：作为政策匹配和服务进度跳转后的内部页面，不再作为独立菜单入口。

> 为兼容已有链接和内部跳转，上述页面路由仍保留，但已设置为不显示在菜单中；本轮没有删除后端接口、数据库字段或企业业务页面。

## 三、管理端企业工作台

### 保留并突出

- 服务进度
- 风险与待办
- 近期申报
- 资料完整度
- 审核与补正操作

### 入口分层

顶部操作入口分为两层：

1. **核心操作**
   - 企业资料
   - 申报管理
   - 审核待办
2. **更多资料与工具**
   - 财税资料
   - 人员资料
   - 知识产权
   - 证据链
   - 档案资料

### 降低优先级

- 最近操作：保留现有数据和组件，改为折叠展示，不抢占首屏注意力。
- 健康评分：不再作为工作台核心指标展示；资料完整度和进行中申报更直接服务于当前业务链路。
- 证据链、档案、数据同步等高级能力：保留原有路由和权限，仅从核心操作区下沉到“更多资料与工具”。

## 四、明确未删除的内容

- 未删除后端接口和数据库字段。
- 未删除仍被服务进度、企业资料和申报详情引用的业务页面和路由，历史链接和内部跳转继续有效。
- 仅删除了客户端布局中已无引用的协同中心组合逻辑文件。
- 未改变企业隔离、企业 ID、申报 ID 传递逻辑。
- 未改变资格校验、审核动作或申报结果语义。
- 未新增正式归档实体。

## 五、后续建议

如果后续继续优化，可按用户角色分别验证：

- 企业用户：是否能在首页明确知道“当前进行到哪一步、下一步做什么”。
- 服务人员：是否能从风险与待办直接处理需要补正的资料或申报。
- 管理人员：高级资料、证据链和操作记录是否仍能在两次点击内找到。
