# IAM/SSO 上线与验收清单

每个接入 IAM 的业务系统必须完成本清单。所有项目应有明确负责人和记录。

## 1. 配置准备

- [ ] 已确定唯一 `appCode`，且与其他系统不重复。
- [ ] 已登记前端回调地址、登出地址、门户类型和默认首页。
- [ ] 已创建 OAuth Client，浏览器 SPA 使用 `public` Client。
- [ ] 已配置 `companySourceSystem`，或确认系统没有公司归属数据。
- [ ] 已创建最小角色、权限码、菜单和首批用户应用访问权。
- [ ] 已明确公司资料由业务系统维护，IAM 仅同步公司授权索引。

## 2. 前端验收

- [ ] 未登录访问受保护路由会跳转 IAM `/oauth/authorize`。
- [ ] IAM 登录后返回登记的回调地址，`state` 校验失败时拒绝登录。
- [ ] 同一浏览器访问第二个已接入系统，不再要求输入密码。
- [ ] 前端只保存短期 access token；refresh token 使用 SDK 与 `sessionStorage`。
- [ ] 收到 `401` 只刷新和重试一次，刷新失败后回到登录页。
- [ ] 菜单来自 `/iam/me/apps/:appCode/menus`，不会混入其他应用菜单。
- [ ] 退出时调用统一 `/oauth/logout`，并清理本地用户、菜单、权限与公司状态。

## 3. 后端验收

- [ ] 每个受保护 API 都验证 Bearer JWT。
- [ ] JWT 验证包含 RS256 签名、JWKS `kid`、`iss`、`aud`、`app_code`、`exp` 和 `nbf`。
- [ ] 不接受前端提交的用户 ID、角色、权限或公司范围作为可信身份依据。
- [ ] 所有业务写接口和敏感读接口有权限码检查。
- [ ] 未授权权限码返回 `403`，不是 `200` 空数据或默认放行。
- [ ] 公司数据先取 IAM 公司范围；IAM 不可用时拒绝公司数据请求。
- [ ] `assigned` 用户不能读取未授权公司；`all` 只覆盖当前 `companySourceSystem` 数据域。
- [ ] 后端不使用平台部门作为公司数据过滤条件。

## 4. 数据迁移验收

- [ ] 用户原始 ID 映射已验证：`source_user_id`。
- [ ] 公司原始 ID 映射已验证：`source_company_id`。
- [ ] 公司名称、状态变更的同步任务已配置幂等重试。
- [ ] 已配置负责人、成员、项目老师与默认公司。
- [ ] 已确认业务公司详情页仍读取业务库，不读取 IAM 公司索引作为主数据。

## 5. 安全与运维验收

- [ ] 生产 IAM 使用固定 RSA 私钥、固定 `IAM_JWT_KEY_ID`，并保留轮换期间旧公钥。
- [ ] 回调 URL 为 HTTPS 且精确登记；不存在通配符回调。
- [ ] 生产关闭 bootstrap 登录：`IAM_ENABLE_BOOTSTRAP_LOGIN=false`。
- [ ] 管理员账号使用强密码并拥有最小必要 IAM 权限。
- [ ] IAM、业务前端、业务后端 CORS 与 Cookie 域配置已验证。
- [ ] IAM 审计日志可查询登录、令牌和管理操作，且不包含密码、Token、Cookie、Client Secret。
- [ ] IAM 不可用、JWKS 不可用、上下文超时的告警已配置。

## 6. 回归用例

| 场景 | 预期 |
| --- | --- |
| 无令牌访问业务 API | `401` |
| 错误 `iss`、`aud` 或 `app_code` | `401` |
| 无权限码访问敏感 API | `403` |
| 用户访问未授权公司 | `403` 或空集合，取决于业务接口约定，但不能泄露数据 |
| 已分配公司用户访问本公司 | 正常返回 |
| `dataScope=all` 用户 | 仅返回本应用数据源内公司 |
| 刷新令牌轮换后重用旧 token | 失败 |
| 统一登出后使用 refresh token | 失败 |
| 用户停用后新建 SSO 会话 | 失败 |
| 应用停用后授权码或刷新 | 失败 |

## 7. 上线步骤与回滚

1. 先在测试环境完成 IAM 配置和全部回归用例。
2. 灰度前端 IAM 登录，保留后端旧认证仅作短时兼容。
3. 验证 SSO 回调、菜单、权限和公司范围。
4. 灰度后端 JWT 验证与公司范围 Guard。
5. 监控 `401`、`403`、JWKS 失败、IAM 上下文超时和登录失败率。
6. 验收后下线本系统的用户、角色、权限、菜单与公司范围管理入口。
7. 回滚时仅切回本系统已保留的认证兼容路径；不得删除 IAM 用户、应用或授权记录。
