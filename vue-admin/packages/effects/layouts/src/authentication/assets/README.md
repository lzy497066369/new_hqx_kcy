# Login Background

`golden-gate.webp` is a photograph of the Golden Gate Bridge in San Francisco, obtained from the Unsplash image CDN. It is stored locally to avoid a third-party network dependency on the login page.

- Original asset: https://images.unsplash.com/photo-1501594907352-04cda38ebc29
- Download variant: width 1920px, WebP, quality 85
- License reference: https://unsplash.com/license
- Website usage guidance: https://help.unsplash.com/en/articles/2612317-can-i-use-unsplash-images-as-part-of-a-product-to-sell

The background blur and overlay are applied in CSS; the asset is not pre-blurred.
